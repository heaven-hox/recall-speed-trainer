# 想起速度トレーナー

V式速記文字などの画像・文字を見て、対応する読みを思い出す練習用のローカルWebアプリです。正答率、最初の打鍵までの時間、判定確定までの時間を記録します。単文字と単語の両方に対応します。

Pythonで手元のサーバーを起動し、ブラウザで操作します。アカウントや外部サービスは不要です。デックと履歴はブラウザ内のIndexedDBに保存し、取り込んだカードのスクリプトは実行しません。

## 起動

Python 3.10以降が必要です。実行時の追加依存は `zstandard` のみで、Node.jsやフロントエンドのビルドは不要です。

[uv](https://docs.astral.sh/uv/getting-started/installation/) を導入し、リポジトリ内で次を実行してください。仮想環境の作成と依存関係の導入も自動で行います。

```sh
uv run --locked server.py
```

依存関係の定義は `pyproject.toml`、固定バージョンと配布ファイルのハッシュは `uv.lock` で管理します。依存関係だけを先に導入する場合は `uv sync --locked` を使えます。Windowsでも同じuvコマンドです。

uvを使わない場合は、従来のvenv・pipでも起動できます。

```sh
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

Windowsでは、上の `.venv/bin/python` を `.venv\Scripts\python.exe` に置き換えてください。

表示されたアドレスをブラウザで開きます。標準ポートは8765、変更する場合は `uv run --locked server.py --port 8766`。停止はターミナルで Ctrl+C です。サーバーはループバックアドレスだけで待ち受けます。

**いつも同じブラウザ・同じホスト名・同じポートを使ってください。** `localhost` と `127.0.0.1`、異なるポートやブラウザでは保存領域が別になります。ブラウザデータを削除すると履歴も消えるため、バックアップJSONを保存してください。

## デックを取り込む

1. 「デック読込」から `.apkg` またはCSV/TXTを選択します。
2. ノートタイプごとに「問題」「正解」「補足」を選び、プレビューを確認します。
3. 「取り込む」を押し、学習対象のデックをチェックします。

### カードごとの出題設定

取り込みプレビューの「出題」チェック欄で、カードごとの有効・無効を選べます。チェックを外したカードも保存され、後から有効にできます。新規カードと、設定のない旧データはすべて有効です。

取り込み後は、デック横の「カード選択」を開いて変更します。たとえば「あ・か・さ・た・な」だけ練習する場合は「表示中をすべて無効」を押してから、その5枚だけチェックして保存します。覚えたら同じ操作で「う・く・す・つ・ぬ」に切り替えられます。

- 読み・補足・問題文で検索できます。検索中の一括操作は、表示中のカードだけが対象です。
- 有効なカードだけを、すべての出題方式で使います。全カードが無効なら学習を開始できません。
- 学習中は変更できません。中断中も含め、一度終了してから変更してください。
- 有効・無効を切り替えても学習履歴や苦手の重みはリセットしません。学習履歴の「表示対象」で、選択デック内の全カード・有効なカードのみを切り替えられます。一覧と上部4指標は同じ対象で集計し、表示設定も再読み込み・バックアップ復元で引き継ぎます。
- 選択はブラウザに保存し、同じデックの再取り込み・バックアップ復元でも引き継ぎます。「キャンセル」では変更を保存しません。

### フィールド

「フィールド」は、カードに格納された名前付きの項目です。たとえば次のように指定します。

| フィールド | 内容 | 用途 |
|---|---|---|
| 表面 | 速記文字の画像 | 問題 |
| 裏面 | あんか | 正解 |
| 単語 | 安価 | 補足（回答後に表示） |

正解は、ひらがな（長音符 `ー` を含む）または英字だけです。漢字、カタカナ、空白、英字のハイフン、ひらがなと英字の混在は対象外です。補足にはこの制限はありません。非対応カードは理由を表示して除外します。

Ankiの新形式 `collection.anki21b`（Zstandard圧縮DB・protobufメディア一覧）と旧形式に対応します。今回提供された単文字44枚・単語9枚のパッケージで動作を確認しています。すべてのAnkiバージョン・ノートタイプとの完全互換を保証するものではありません。

問題からテキストと同梱画像（JPEG / PNG / GIF / WebP）を取り出します。Ankiテンプレートの装飾・条件式・逆向きカードの自動再現、穴埋め、音声、SVG、JavaScriptは扱いません。外部画像は読み込みません。提供された学習用デックはリポジトリに同梱していません。

同じカードの再取り込みは更新になります。問題や正解が変わったカードは成績をリセットし、過去ログを残します。補足だけの変更では成績を維持します。ファイルに含まれなくなったカードを自動削除することはありません。

### CSV / TXT

UTF-8（BOM付きも可）、先頭行に列名が必要です。CSVはカンマ、TSV/TXTはタブ区切りです。CSV/TXTの問題はプレーンテキストとして扱います。

```csv
question,answer,extra,deck,id
安価,あんか,読みの練習,日本語,1
りんご,apple,英単語,英語,2
```

必須列は `question,answer`、任意列は `extra,deck,id`。`deck` 省略時はファイル名をデック名にします。同じ問題を複数登録する場合や、問題文を変更しても同じカードとして扱いたい場合は、固有の `id` を指定してください。

## 練習

- **重複ありランダム**：問題数を指定。連続して同じカードも出ます。
- **重複なしランダム**：周回数を指定。周ごとに全カードを並べ替えます。周回の境界では同じカードが連続する場合があります。
- **苦手優先**：未学習カードを重複なしで1回ずつ出し、その後は低正答率のカードほど出やすくします。未学習が残れば、次のセッションでも残りから始めます。

IMEをオフにし、ひらがなはローマ字、英字はそのまま入力します。

| 正解 | 入力例 |
|---|---|
| し | `shi` / `si` |
| あんか | `anka` / `annka` / `an'ka` |
| あんな | `anna` / `annna` |
| なんあ | `nanna` / `nan'a` |
| きゃ | `kya` / `kixya` / `kilya` |
| がっこう | `gakkou` / `gaxtukou` |
| こーひー | `ko-hi-` |

**逐次判定**は、正解へ続けられない入力になった時点で不正解です。末尾の「ん」は `nn` または `n'` で確定し、`n` 単独では保留します。**Enter判定**では入力中の修正が可能で、末尾の `n` 単独もEnterで確定できます。空欄のEnterは不正解です。

英字の大文字小文字はGUIで切り替えます。貼り付け、IME入力、キーを押しっぱなしにした自動反復は回答入力として使いません。打鍵ログには修飾キー・反復イベントも記録します。

待機時間は初期値500ms、0〜10,000ms、10ms刻みです。0msでは結果表示欄への一時表示を省き、前回結果欄を更新します。保存が完了するまでは次問に進みません。

「中断」やタブ切替・ウィンドウのフォーカス喪失で停止します。回答中だった問題は中断ログを残し、再開時に出し直します。中断は正答率や平均時間に含めません。学習中の設定は固定し、カード別の正解一覧も隠します。

## 時間・履歴・リセット

- **初動時間**：問題画像のデコード後、表示を有効にした時点から最初の回答入力・編集キーまで。Shiftなどの修飾キー単独やEnterだけでは初動になりません。
- **合計時間**：同じ開始点から正誤確定まで。結果表示中・保存待ちの時間を含みません。
- 日時はISO8601 UTC、経過時間は `performance.now()` で記録します。画面の表示・OS・入力機器の遅延を含む実用上の計測で、実験用の精密計測ではありません。
- カード別の時間平均は正答時だけで集計します。初動のない回答は初動平均から除外します。

書き出しは以下の4種類です。

| 出力 | 内容 |
|---|---|
| バックアップJSON | 画像・デック・設定・全ログ・リセット履歴。再読み込み可能 |
| 生ログJSON | セッション設定、問題ごとの回答、打鍵と経過時間、リセット履歴。画像は内部名で参照 |
| 回答CSV | 日時、問題、正解、補足、入力、正誤、初動・合計時間など |
| 集計CSV | カードごとの現在の正答率・正答時平均時間など |

バックアップ読込は、現在の保存内容を丸ごと置き換えます。確認ダイアログの前に形式と参照関係を検査し、1トランザクションで反映します。

**成績リセットは、選択中のデックまたは全デックが対象です。** 対象カードを未学習に戻し、出題の重みと通常の集計をやり直します。過去の生ログは削除しません。先にバックアップを保存し、ファイルを確認してください。

強制終了・再読み込みの途中で未確定だった回答の打鍵は復元しません。保存済みの回答は保持します。別のタブで同時に操作せず、1つのタブで使用してください。

## 開発・確認

```sh
uv run --locked python -m unittest discover -s tests -v
npm test
```

`npm test` はNode.js 20以降の標準テストランナーを使います。npmパッケージのインストールは不要です。

任意のブラウザ確認には、別途PythonのPlaywrightとChromiumが必要です。`tests/browser_check.py` は `/usr/bin/chromium` を使い、自分で一時サーバーを起動します。

```sh
uv run --locked --with playwright python tests/browser_check.py --apkg /path/to/単文字.apkg --apkg /path/to/単語.apkg
```

上記の実デック指定は今回の確認データ用です。指定しなくてもCSV・Enter判定・中断を検証できます。判定・出題・集計の詳細は [SPEC.md](SPEC.md) を参照してください。
